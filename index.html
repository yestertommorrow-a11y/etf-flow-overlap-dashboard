ETF Flow & Overlap Dashboard

Fund flows · 1-vs-1 overlap · sector weights · correlation · holdings change — from free TickerInside data — plus Sinclair volatility estimators from daily OHLC. Browse every fund of any issuer · Invesco funds get holdings from SEC Form N-PORT and weight changes from quarterly reports.

⚠ Upfront: no flow series for Invesco-related funds — flows exist only for ETFs read daily from iShares, SPDR or Global X files (etc. QQQ is Invesco, so it has none). SEC-filed funds (Invesco, Vanguard…) publish nothing daily. For those use the Holdings Change tab, where Invesco works from quarterly SEC reports.

Filters the covered universe server-side (/screen, no key), so any issuer works — type iShares, Vanguard, SPDR, Global X… Pick buttons fill the other tabs: A/B set the compare tabs, ＋ appends to Correlation and Holdings Change.

TickerInside publishes weekly returns, not daily OHLC — so this tab takes prices directly: a daily Yahoo Finance CSV (Date, Open, High, Low, Close, Adj Close) for the fund and, optionally, a benchmark. Load latest SOXL + SOXX fetches the published CSVs next to this page in one click — no file picker; they refresh daily after the US close, so they are only as fresh as the last refresh. Browsers cannot fetch Yahoo directly (CORS), which is why the CSVs are published here. The estimators run here in the browser. The tools/vol_snapshot.py helper instead runs the real volatility-trading library and writes a JSON snapshot this tab loads unchanged, so Python numbers and browser numbers sit in the same view.

Data: TickerInside (CC BY 4.0), issuer holdings history and SEC Form N-PORT filings. Overlap = Σ min(wᵢᴀ, wᵢʙ) over shared holdings. Flows = net creations/redemptions measured from daily issuer files (ETFs read daily only). Holdings history and flows exist only for ETFs read daily from issuer files; other funds (Invesco, Vanguard…) get holdings from SEC filings and weight changes from quarterly reports instead. Volatility estimators follow Euan Sinclair's Volatility Trading; the browser port mirrors the models of jasonstrimpel/volatility-trading (GPL-3.0), used unmodified by the optional Python snapshot builder. OHLC prices are yours (Yahoo CSV or a snapshot), not TickerInside. Not investment advice.
